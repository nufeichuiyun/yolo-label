# RKNN Toolkit2 x64 PC 安装指南
## 📋 项目简介

本项目提供了在 **x64 PC** 上安装和配置 **RKNN Toolkit2** 的完整解决方案。RKNN Toolkit2 是瑞芯微官方提供的神经网络推理工具包，支持模型转换、量化和推理等功能。

### ✨ 主要特性

- 🔧 **兼容性保证**: 针对 x86_64 架构和 Python 3.10 优化
- 📦 **一键安装**: 提供自动化安装脚本
- 🎯 **即用即得**: 安装完成后可直接进行模型转换和推理

## 🖥️ 系统要求

### 硬件要求
- **处理器**: x86_64 架构
- **内存**: 建议 4GB 以上
- **存储**: 建议 2GB 以上可用空间

### 软件要求
- **操作系统**: Linux (推荐 Ubuntu 22.04)
- **Python**: 3.10.x
- **pip**: 最新版本

## 📦 文件说明

- `README.md` - 项目说明文档
- `requirements_cp310-2.3.2.txt` - Python 依赖包列表
- `rknn_toolkit2-2.3.2-cp310-cp310-manylinux_2_17_x86_64.manylinux2014_x86_64.whl` - RKNN Toolkit2 安装包
- `install_rknn_x64.sh` - 一键安装脚本

## 🚀 快速安装

运行自动化安装脚本：

```bash
./install_rknn_x64.sh
```
