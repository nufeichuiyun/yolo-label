# RK3588专用模型转换程序使用说明 (简化版)

## 程序特点

- 🎯 **专门针对RK3588平台**：无需指定平台参数
- 🔄 **自动生成dataset文件**：只需提供图片文件夹，自动生成量化校准用的dataset
- 🚀 **极简使用流程**：只需两个参数，一键转换
- 🧹 **自动清理**：转换完成后自动清理临时文件
- 📁 **智能输出路径**：自动保存到输入模型同目录
- �� **固定配置**：固定int8量化，默认不显示详细信息

## 使用方法

### 环境要求

- 🖥️ **运行平台**：ubuntu22.04 x64
- 📦 **依赖安装**：运行前需要安装RKNN-Toolkit2包

### 基本用法

```bash
# 最简单的用法：转换模型，使用int8量化
python3 convert_rk3588.py model.onnx ./images/
```

### 参数说明

| 参数 | 说明 | 必需 | 示例 |
|------|------|------|------|
| `onnx_path` | ONNX模型文件路径 | ✅ | `./yolo_model.onnx` |
| `image_folder` | 包含量化校准图片的文件夹路径 | ✅ | `./calibration_images/` |

### 支持的图片格式

- JPG/JPEG
- PNG  
- BMP

## 使用示例

### 示例1：基本转换
```bash
# 假设您有一个训练好的YOLO模型
python3 convert_rk3588.py ./yolo_model.onnx ./calibration_images/
```

### 输出说明
- 输入：`./yolo_model.onnx`
- 输出：`./yolo_model.rknn` (自动保存到同目录)
- 量化：int8 (固定)
- 详细信息：不显示 (默认)

## 图片选择建议

### 数量要求
- **推荐**：50-200张图片
- **最少**：20张图片
- **最多**：500张图片（过多会增加转换时间）

### 质量要求
- 图片清晰，无严重噪声或模糊
- 分辨率与训练时保持一致
- 覆盖模型实际应用的各种场景

### 分布建议
- 主要类别：70-80%
- 次要类别：15-20%
- 罕见类别：5-10%
- 包含不同光照、角度、背景条件

## 转换流程

1. **自动生成dataset**：扫描图片文件夹，生成临时dataset文件
2. **配置模型**：设置RK3588平台相关参数
3. **加载ONNX**：读取您的训练模型
4. **构建RKNN**：进行int8量化校准和模型转换
5. **导出模型**：生成最终的RKNN模型文件
6. **清理资源**：自动删除临时文件

## 注意事项

- 确保图片文件夹路径正确
- 图片文件应该有读取权限
- 转换过程中会占用较多内存和CPU资源
- 建议在转换完成后验证模型精度
- 输出文件会自动覆盖同名的.rknn文件
